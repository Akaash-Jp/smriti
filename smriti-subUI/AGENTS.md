# Smriti Project Guidelines

## Technology

- Build the entire website with simple HTML, CSS, and JavaScript.
- Python may be used for the backend.
- If another tool is needed, choose something easy to learn and explain.

## Audience and Clarity

- Write code that a high-school student can understand.
- Explain ideas clearly and avoid unnecessary technical language.
- Keep file structure, names, and logic simple.

## Documentation

- Document every block of code with short, easy-to-understand comments.
- Use clear formatting so students can connect each explanation to the code it describes.
- Explain why important choices were made, not only what the code does.

## Working Rule

Keep these guidelines in mind whenever code is added to or changed in this project.
